# 🎓 UniTask — University Task & Deadline Tracker

> **A Modern, Optimized Dark Glassmorphic Web Application for University Students**  
> ভার্সিটির সব Home Task, Assignment, Presentation, Quiz ও Exam ডেডলাইন সহজে এবং স্টাইলিশভাবে ট্র্যাক করার স্মার্ট সমাধান।

---

## 🌟 Key Features

### A. 📊 Dashboard
- **Total Tasks**: সর্বমোট অ্যাসাইনমেন্ট ও টাস্ক কাউন্ট
- **Completed Tasks**: সফলভাবে সম্পন্ন হওয়া কাজের তালিকা
- **Pending Tasks**: এখনো জমা দেওয়া বাকি থাকা কাজ
- **Overdue Tasks**: ডেডলাইন পার হয়ে যাওয়া কাজের লাল গ্লোয়িং অ্যালার্ট
- **Today's Tasks**: আজকের মধ্যে জমা দেওয়ার ডেডলাইন
- **Upcoming Deadlines**: পরবর্তী ৭ দিনের প্রয়োজনীয় সব কাজ
- **Task Completion Percentage**: ডায়নামিক প্রোগ্রেস বার ও অগ্রগতি মেট্রিক

### B. ➕ Task Add & Details
- **Task Title**: কাজের নাম (উদাঃ *Data Structures Assignment 2*)
- **Description**: কাজের বিস্তারিত সিলেবাস ও নির্দেশনা
- **Start Date & Deadline**: শুরুর সময় ও জমার ডেডলাইন (কুইক প্রিসেটঃ *Today Midnight, Tomorrow, In 3 Days, In 1 Week*)
- **Priority Levels**: `Low` (সবুজ), `Medium` (নীল), `High` (হলুদ), `Urgent` (লাল পালসিং গ্লো)
- **University Categories**:
  - 📝 **Assignment** (অ্যাসাইনমেন্ট)
  - 🎯 **Quiz / Exam** (কুইজ ও পরীক্ষা)
  - 🎤 **Presentation** (প্রেজেন্টেশন ও স্লাইড ডেক)
  - 📚 **Study** (রিডিং ও ক্লাস নোট)
  - 👤 **Personal** (ব্যক্তিগত কাজ)
  - 💼 **Work** (প্রজেক্ট / ইন্টার্নশিপ)
- **Status**: `Pending (To Do)`, `In Progress`, `Completed`
- **Smart Reminders**: ডেডলাইনের ১ দিন আগে ও ১ ঘণ্টা আগে স্বয়ংক্রিয় নোটিফিকেশন

### C. 📋 Task Management
- **Kanban Board View**: ৩টি কলাম — `To Do`, `In Progress`, `Completed`
- **List View**: ডেডলাইন অনুযায়ী সর্টেবল আধুনিক তালিকা
- **Interactive Actions**: কুইক স্ট্যাটাস টগল, কনফেটি সেলিব্রেশন, এডিট এবং ডিলিট

### D. 📅 Calendar & Deadline Tracker
- **Monthly Calendar Grid**: পুরো মাসের ডেডলাইন ক্যালেন্ডার ভিউ
- **Weekly View**: সপ্তাহের দিনভিত্তিক ডেডলাইন
- **Date Inspector**: যেকোনো তারিখে ক্লিক করে ওই দিনের কাজ দেখা
- **Overdue Highlight**: ডেডলাইন মিস করা কাজগুলোকে আলাদাভাবে হাইলাইট করা

### E. 🔔 Notification System
- **1 Day Before Reminder**: ডেডলাইনের ২৪ ঘণ্টা আগে সতর্কবার্তা
- **1 Hour Before Reminder**: ডেডলাইনের ১ ঘণ্টা আগে জরুরি অ্যালার্ট
- **Task Overdue Notification**: ডেডলাইন পার হলে তৎক্ষণাৎ অ্যালার্ট
- **Browser Push Notification**: ব্রাউজার পুশ নোটিফিকেশন সুবিধা
- **In-App Notification Center**: বেল আইকন সহ আনরিড ব্যাজ ও ড্রপডাউন হিস্টোরি

### F. ⚡ Advanced Features
- **🔍 Search & Filter**: টাইটেল, নোট ও ডেসক্রিপশনে লাইভ সার্চ এবং ক্যাটাগরি/প্রায়োরিটি ফিল্টারিং
- **🔁 Recurring Tasks**: `Daily`, `Weekly`, `Monthly` স্বয়ংক্রিয় পুনরাবৃত্তি
- **☑️ Subtasks Checklist**: বড় কাজকে ছোট ছোট স্টেপে ভাগ করার সাবটাস্ক অপশন
- **📝 Student Notes**: অ্যাসাইনমেন্টের সাথে ড্রাইভ লিংক বা লেকচার নোট সেভ রাখা
- **⏱️ Pomodoro Focus Timer**: ২৫ মিনিট স্টাডি ফোকাস + ৫ মিনিট রিস্টোরিং ব্রেক + সাউন্ড অ্যালার্ট
- **🌓 Dark / Light Mode**: প্রিমিয়াম ডার্ক গ্লাস মরফিজম এবং লাইট মোড টগল
- **📈 Analytics & Trends**: ৭ দিনের টাস্ক কমপ্লিশন ট্রেন্ড এবং ক্যাটাগরি ডিস্ট্রিবিউশন
- **📜 History & Activity Log**: পুরোনো কাজের আর্কাইভ এবং সাম্প্রতিক অ্যাক্টিভিটি লগ
- **📥 CSV Export**: ১ ক্লিকে পুরো ডেডলাইন শিট CSV ফাইলে ডাউনলোড

### G. 🛡️ User & Security Guarantees
1. **সুদর্শন আইকন ও গ্লাস ডিজাইন**: Lucide Iconic ড্যাশবোর্ড ও প্রিমিয়াম Dark Glassmorphism।
2. **অ্যাসাইনমেন্ট, প্রেজেন্টেশন ও কুইজ ম্যানেজমেন্ট**: প্রতিটি ক্যাটাগরির জন্য ডেডিকেটেড ফিল্টারিং ও কার্ড।
3. **একাউন্ট তৈরি ও লগইন**: সম্পূর্ণ নিরাপদ JWT ও Bcrypt অথেনটিকেশন।
4. **১০০% ইউজার ডাটা আইসোলেশন**: একজন লগইন করলে অন্য ইউজারের ডাটা দেখতে পারবে না (কড়া `userId` ফিল্টারিং)।
5. **ডাটা নিরাপদ ও রিফ্রেশ-সেফ**: পেজ রিফ্রেশ করলেও ডাটা হারাবে না এবং স্বয়ংক্রিয়ভাবে লগআউট হবে না।
6. **সুন্দর প্রোফাইল সেকশন**: নিজের ফটো আপলোড, রিমুভ, প্রিভিউ ও প্রি-সেট অ্যাভাটার পরিবর্তনের সুবিধা।

## 🚀 How to Run the App

### Option 1: Quick Start (Recommended)
এক কমান্ডেই ব্যাকএন্ড এবং সম্পূর্ণ বিল্ট ওয়েব অ্যাপ চালু করুন:

```bash
# UniTask ফোল্ডারে টার্মিনাল ওপেন করুন
node backend/server.js
```

ব্রাউজারে ভিজিট করুন:  
👉 **`http://localhost:5000`**

---

### Option 2: Development Mode (Hot Reload)
যদি আপনি ফ্রন্টএন্ড কোডে কোনো পরিবর্তন করতে চান এবং লাইভ রিলোড চান:

```bash
# 1. ব্যাকএন্ড চালু করুন (একটি টার্মিনালে)
node backend/server.js

# 2. ফ্রন্টএন্ড ডেভ সার্ভার চালু করুন (আরেকটি টার্মিনালে)
cd frontend
npm run dev
```

ব্রাউজারে ভিজিট করুন:  
👉 **`http://localhost:3000`**
